# ระบบจัดตารางเรียน ตารางสอน แผนกอิเล็กทรอนิกส์

เว็บแอปสำหรับจัดตารางเรียน (ตามกลุ่มเรียน) ตารางสอน (ตามครู) และตารางการใช้ห้อง
ใช้ร่วมกันได้หลายคน ทุกคนที่เปิดหน้าเว็บเห็นการแก้ไขทันที

- จัดอัตโนมัติ แล้วปรับแก้เองด้วยการลาก-วาง หรือคลิกเลือก
- ตรวจเวลาชนของครู กลุ่มเรียน และห้อง
- แก้ไขรายวิชา ครู กลุ่มเรียน ห้อง ได้ในหน้าเว็บ
- ส่งออกเป็นไฟล์ Excel รูปแบบเดียวกับไฟล์เดิม (ตารางกลุ่ม / ครู / ห้อง พร้อมช่องลงนาม)

ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ใช้ Node.js 18 ขึ้นไปเท่านั้น

## รันในเครื่อง

```bash
npm start
# เปิด http://localhost:3000
```

ข้อมูลเก็บในโฟลเดอร์ `data/` (สร้างให้อัตโนมัติ) ครั้งแรกจะโหลดข้อมูลตั้งต้นจาก `seed/`
ถ้าต้องการเริ่มใหม่จากข้อมูลตั้งต้น ให้ลบโฟลเดอร์ `data/`

## ขึ้น GitHub

```bash
git init
git add .
git commit -m "ระบบจัดตารางเรียน ตารางสอน"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
git push -u origin main
```

แนะนำให้ตั้ง repo เป็น Private เพราะมีชื่อครูในไฟล์ `seed/`

## Deploy บน Railway

1. เข้า railway.com → **New Project** → **Deploy from GitHub repo** → เลือก repo นี้
2. **ผูก Volume (สำคัญที่สุด)** คลิกขวาที่ service → **Attach Volume** → Mount path: `/data`
   ถ้าไม่มี Volume ข้อมูลทั้งหมดจะหายทุกครั้งที่ push โค้ดใหม่ (หน้าเว็บจะขึ้นแถบแดงเตือน)
   ระบบตรวจพบ Volume เองอัตโนมัติ ไม่ต้องตั้ง `DATA_DIR` (ถ้าเคยตั้ง `DATA_DIR` ไว้ ต้องชี้ไปที่ `/data` เท่านั้น หรือลบตัวแปรนี้ทิ้ง)
3. แท็บ **Variables** (ไม่บังคับ แต่แนะนำ)
   | ตัวแปร | ค่า | ความหมาย |
   |---|---|---|
   | `APP_PASSWORD` | รหัสผ่านที่ตั้งเอง | ล็อกทั้งเว็บด้วยรหัสผ่าน (ไม่ใส่ = ใครมีลิงก์ก็แก้ได้) |
   | `APP_USER` | เช่น `elec` | ชื่อผู้ใช้ตอนเข้าสู่ระบบ (ค่าเริ่มต้น `admin`) |
4. **Settings** → **Networking** → **Generate Domain**
5. ตรวจว่าเก็บข้อมูลถาวรแล้ว: เปิด `https://<โดเมน>/api/info` ต้องได้ `"persistent":true`
   และใน Deploy Logs จะเห็น `data: /data`

## ก่อนอัปเดตโค้ดทุกครั้ง

1. เปิดแท็บ **ตั้งค่า / ส่งออก** → **ดาวน์โหลดไฟล์สำรอง** (ได้ไฟล์ `timetable-backup_วันที่.json`)
2. push โค้ดใหม่ขึ้น GitHub แล้วรอ Railway deploy เสร็จ
3. ถ้าข้อมูลหาย ให้กด **กู้คืนจากไฟล์สำรอง…** แล้วเลือกไฟล์ที่ดาวน์โหลดไว้

ไฟล์สำรองนี้ใช้ได้ทั้งเวอร์ชันบน Railway และเวอร์ชันบน claude.ai ย้ายข้อมูลข้ามกันได้

## โครงสร้าง

```
server.js              เซิร์ฟเวอร์ (API + ส่งการแก้ไขแบบเรียลไทม์ด้วย Server-Sent Events)
public/index.html      หน้าเว็บทั้งหมด
public/claude-shim.js  ตัวเชื่อมหน้าเว็บกับเซิร์ฟเวอร์
seed/                  ข้อมูลตั้งต้นที่ดึงจาก "ตารางอิเล็กทรอนิกส์ 2569-2.xlsx"
```
