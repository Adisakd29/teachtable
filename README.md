# ระบบจัดตารางเรียน ตารางสอน แผนกอิเล็กทรอนิกส์

เว็บแอปสำหรับจัดตารางเรียน (ตามกลุ่มเรียน) ตารางสอน (ตามครู) และตารางการใช้ห้อง
ใช้ร่วมกันได้หลายคน ทุกคนที่เปิดหน้าเว็บเห็นการแก้ไขทันที

- จัดอัตโนมัติ แล้วปรับแก้เองด้วยการลาก-วาง หรือคลิกเลือก
- ตรวจเวลาชนของครู กลุ่มเรียน และห้อง
- แก้ไขรายวิชา ครู กลุ่มเรียน ห้อง ได้ในหน้าเว็บ
- ส่งออกเป็นไฟล์ Excel รูปแบบเดียวกับไฟล์เดิม (ตารางกลุ่ม / ครู / ห้อง พร้อมช่องลงนาม)

ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ใช้ Node.js 18 ขึ้นไปเท่านั้น

## รันในเครื่อง

```bash
npm start
# เปิด http://localhost:3000
```

ข้อมูลเก็บในโฟลเดอร์ `data/` (สร้างให้อัตโนมัติ) ครั้งแรกจะโหลดข้อมูลตั้งต้นจาก `seed/`
ถ้าต้องการเริ่มใหม่จากข้อมูลตั้งต้น ให้ลบโฟลเดอร์ `data/`

## ขึ้น GitHub

```bash
git init
git add .
git commit -m "ระบบจัดตารางเรียน ตารางสอน"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
git push -u origin main
```

แนะนำให้ตั้ง repo เป็น Private เพราะมีชื่อครูในไฟล์ `seed/`

## Deploy บน Railway

1. เข้า railway.com → **New Project** → **Deploy from GitHub repo** → เลือก repo นี้
2. **ผูก Volume (สำคัญที่สุด)** คลิกขวาที่ service → **Attach Volume** → Mount path: `/data`
   ถ้าไม่มี Volume ข้อมูลทั้งหมดจะหายทุกครั้งที่ push โค้ดใหม่ (หน้าเว็บจะขึ้นแถบแดงเตือน)
   ระบบตรวจพบ Volume เองอัตโนมัติ ไม่ต้องตั้ง `DATA_DIR` (ถ้าเคยตั้ง `DATA_DIR` ไว้ ต้องชี้ไปที่ `/data` เท่านั้น หรือลบตัวแปรนี้ทิ้ง)
3. แท็บ **Variables** (ไม่บังคับ แต่แนะนำ)
   | ตัวแปร | ค่า | ความหมาย |
   |---|---|---|
   | `APP_PASSWORD` | รหัสผ่านที่ตั้งเอง | ล็อกทั้งเว็บด้วยรหัสผ่าน (ไม่ใส่ = ใครมีลิงก์ก็แก้ได้) |
   | `APP_USER` | เช่น `elec` | ชื่อผู้ใช้ตอนเข้าสู่ระบบ (ค่าเริ่มต้น `admin`) |
   | `ANTHROPIC_API_KEY` | คีย์จาก console.anthropic.com | เปิดปุ่ม "ให้ AI ช่วยร่าง" ในเมนูแผนการสอน (มีค่าใช้จ่ายตามการใช้งาน ไม่ใส่ = ไม่มีปุ่ม AI) |
   | (ไม่ต้องตั้งตัวแปร) | — | "ร่างทั้งเล่ม" ค้นตำรา/เอกสารอ้างอิงจากเว็บด้วยเครื่องมือค้นเว็บของ Claude API (คิดค่าค้นหาเพิ่ม ราว 8 ครั้งต่อเล่ม) ถ้าขึ้นว่ายังไม่เปิดการค้นเว็บ ให้เปิด Web search ใน console.anthropic.com |
   | `OPENAI_API_KEY` | คีย์จาก platform.openai.com | เปิดปุ่ม "ให้ ChatGPT ออกแบบเลย" (ออกแบบหน่วยการเรียนรู้ + ตารางวิเคราะห์) ใช้คู่กับ `ANTHROPIC_API_KEY` ที่ร่างเนื้อหา (คิดค่าใช้จ่ายแยกตามการใช้งาน ใช้ ChatGPT Plus แทนไม่ได้) |
   | `OPENAI_MODEL` | เช่น `gpt-5.5` | รุ่นของ ChatGPT (ไม่บังคับ ถ้าบัญชีไม่มีรุ่นนี้ ระบบลองรุ่นอื่นให้เอง) |
   | `ANTHROPIC_MODEL` | เช่น `claude-sonnet-4-5` | รุ่นโมเดลที่ใช้ (ไม่บังคับ ถ้า AI แจ้งว่าไม่พบโมเดล ให้ใส่ชื่อรุ่นปัจจุบันจาก docs.claude.com) |
4. **Settings** → **Networking** → **Generate Domain**
5. ตรวจว่าเก็บข้อมูลถาวรแล้ว: เปิด `https://<โดเมน>/api/info` ต้องได้ `"persistent":true`
   และใน Deploy Logs จะเห็น `data: /data`

## แผนการจัดการเรียนรู้ (แท็บ "แผนการสอน")

- สร้างแผนจากรายวิชาที่สอน กรอกตามแบบฟอร์ม สอศ. 2567: ปก คำนำ หลักสูตรรายวิชา ตารางวิเคราะห์หน่วย หน่วยการเรียนรู้ ตารางวิเคราะห์พฤติกรรม แผนรายหน่วย (ข้อ 1–10) ใบความรู้ ใบงาน ใบกิจกรรม ใบมอบหมายงาน บรรณานุกรม ภาคผนวก
- บันทึกอัตโนมัติ ส่งออกเป็น Word (.docx) และ PDF
- **อ้างอิงมาตรฐาน** (ส่วน "หลักสูตรรายวิชา"): นำเข้าข้อความหลักสูตรรายวิชา → แยกข้อความ "อ้างอิงมาตรฐาน" (เก็บต้นฉบับ) → ประเภทมาตรฐาน (มาตรฐานฝีมือแรงงานแห่งชาติ / คุณวุฒิวิชาชีพ / มาตรฐานอาชีพอื่น / หลักสูตรยกระดับฝีมือ / อื่น ๆ) → สถานะ NONE / REFERENCE_ONLY / FULL_STANDARD
  - รายละเอียดมาตรฐาน (ความรู้/ความสามารถ/ทัศนคติ หรือ หน่วยสมรรถนะ/สมรรถนะย่อย/เกณฑ์/วิธีประเมิน) มาจากเอกสารมาตรฐานที่นำเข้าเท่านั้น พร้อมแหล่งที่มา
  - ข้อ 2.1 ของแผนและช่องสมรรถนะย่อยในตารางวิเคราะห์ สร้างจากข้อมูลมาตรฐานเท่านั้น (เลือกเชื่อมโยงกับงานย่อย/หน่วย) AI ไม่สร้างข้อมูลมาตรฐาน
  - หน้า "มาตรฐานอาชีพ" ใช้รูปแบบตามประเภทมาตรฐาน และอยู่ในสารบัญเฉพาะเมื่อสร้าง
  - อัปโหลดไฟล์มาตรฐาน/หลักสูตร (PDF, Word, TXT): เวอร์ชัน Railway อ่าน PDF ด้วย pdftotext (ไฟล์สแกนให้ AI ถอดข้อความ ต้องตรวจทาน) · หน้า claude.ai รับ Word/TXT · ไฟล์หลักสูตรทั้งเล่มระบบหาเฉพาะรายวิชาของแผน · มาตรฐานหลายระดับใช้เฉพาะระดับที่อ้างอิง
- **ให้ ChatGPT ออกแบบตารางวิเคราะห์หน่วยการเรียนรู้** (ส่วน "ตารางวิเคราะห์หน่วยการเรียนรู้"): Job → งานหลัก → งานย่อย → ความรู้/ทักษะ ตรวจในตารางก่อนนำเข้า ไม่เปลี่ยนหน่วยการเรียนรู้
- **นำเข้าหน่วยการเรียนรู้จาก ChatGPT** (ส่วน "หน่วยการเรียนรู้"): คัดลอกคำสั่งที่ระบบเตรียมให้ไปถาม ChatGPT แล้ววางคำตอบกลับมา ระบบนำเข้าหน่วย ชั่วโมง ตารางวิเคราะห์ หัวข้อสาระ และงานปฏิบัติ จากนั้น "ให้ AI ร่างทั้งเล่ม" จะร่างแผนและใบช่วยสอนตามกรอบนั้น (ไม่ออกแบบหน่วยใหม่)
- ก่อนส่งออก ระบบตรวจความครบถ้วน (ชั่วโมง ท-ป-นก หัวข้อที่ยังว่าง บรรณานุกรมที่ไม่มีปี อักขระที่ฟอนต์ไม่มี) แล้วแจ้งเตือน ไม่แก้ข้อมูลให้เอง
- บรรณานุกรมรวมจาก "เอกสารอ้างอิง" ของใบช่วยสอนทุกหน่วย ตัดซ้ำ เรียงไทย → ต่างประเทศ ไม่เติมข้อมูลที่ไม่ได้กรอก
- ภาคผนวก ก–จ (เฉลย เกณฑ์ให้คะแนน แบบประเมินคุณลักษณะ แบบบันทึกผลการทดลอง แบบบันทึกหลังสอน) พร้อมสารบัญภาคผนวก

### การส่งออกเอกสาร (สำคัญ)

ระบบมีตัวจัดหน้าเพียงตัวเดียว: สร้างไฟล์ Word ก่อน แล้ว PDF สร้างจากไฟล์ Word ไฟล์เดียวกันบนเซิร์ฟเวอร์ (LibreOffice) จึงแบ่งหน้าเหมือนกัน
- ฟอนต์ TH Sarabun New ฝังในไฟล์ Word (ปรับขนาด/ระยะบรรทัดให้เท่ากับ TH SarabunPSK ในแบบฟอร์ม) เปิดบนเครื่องที่ไม่มีฟอนต์ก็แบ่งหน้าเท่าเดิม
- ข้อความไทยผ่านการจัดรหัส Unicode (NFC, สระอำ, ลำดับสระ/วรรณยุกต์, ตัดเครื่องหมายซ้ำ) ก่อนเขียนลงไฟล์
- section ใช้เฉพาะหน้าปก / ส่วนหน้า (เลขหน้า ก ข) / เนื้อหา (เลขหน้า 1) / หน้าแนวนอน นอกนั้นขึ้นหน้าใหม่ด้วย page break, หัวกระดาษ link to previous
- หน้าปกตามแบบฟอร์ม 2567 ฉบับใหม่: ตรา → แผนการจัดการเรียนรู้ → หลักสูตร → สาขาวิชา → กลุ่มอาชีพ → ประเภทวิชา → รหัสวิชา/วิชา → วิทยาลัย → สอศ./ศธ. (ไม่มีส่วน โดย/ตำแหน่ง/แผนกวิชา)
- สารบัญ: คำนำ (ก) สารบัญ (ข) คำนวณจากหน้าจริง (bookmark `_Toc_lpF*`) เนื้อหาเริ่มหน้า 1
- มาตรฐานอาชีพ: นำเข้าจากไฟล์ประกาศราชกิจจานุเบกษาได้ (คงเลขข้อย่อย) ที่มาพิมพ์ชื่อเอกสารทางการ ไม่พิมพ์ชื่อไฟล์ งานย่อย/หน่วยเชื่อมกับข้อในมาตรฐานจริงเท่านั้น (AI เสนอได้ แต่เลือกเฉพาะเลขข้อที่มีจริง)
- ลำดับเล่ม: หลักสูตรรายวิชา → มาตรฐานอาชีพ (ถ้ามี) → ตารางวิเคราะห์หน่วย → ตารางวิเคราะห์พฤติกรรม (✓) → หน่วยการเรียนรู้ → หน่วยที่ n: แผน → ใบความรู้ → ใบงาน → ใบกิจกรรม → ใบมอบหมายงาน
- เอกสารของแต่ละหน่วยเปิด/ปิดได้ (units[i].docs: info / job / activity / assign / eval) ใบกิจกรรม/ใบมอบหมายงานสร้างเมื่อมีกิจกรรม/งานที่ต่างจากใบงานจริง
- ส่วนขยาย (Intentional Extension) ที่ไม่อยู่ในแบบฟอร์มหลัก: แบบประเมินท้ายหน่วย, บรรณานุกรมท้ายเล่ม, ภาคผนวก ก–จ (เฉลยอยู่ที่ภาคผนวก ก ที่เดียว ใบความรู้ข้อ 8 อ้างถึง)
- หลังสร้างไฟล์ เซิร์ฟเวอร์เรนเดอร์ทุกหน้าแล้วตรวจอัตโนมัติ (`qa/check_export.py`): หน้าปก 1 หน้า, หน้าว่าง, ข้อความ/ตารางล้น, หัวข้อค้าง, เลขหน้าหาย/ซ้ำ, ไทยเพี้ยน, สารบัญ, ภาคผนวก ก–จ, style ซ้ำ, ฟอนต์ฝัง


Railway จะ build จาก `Dockerfile` อัตโนมัติ (ฐาน Debian 13 trixie → LibreOffice 25.x; รุ่น 7.4 ของ Debian 12 ทำให้สระ/วรรณยุกต์ท้ายบรรทัดหลุดขอบขวาเมื่อจัดกระจายแบบไทย ระบบจึงไม่จัดกระจายใน PDF หากพบ LibreOffice รุ่นต่ำกว่า 24.2) ซึ่งติดตั้ง **LibreOffice** และฟอนต์ **TH Sarabun New** (โฟลเดอร์ `fonts/`) ให้
- ไฟล์ Word: เซิร์ฟเวอร์จัดหน้าแล้วเติมเลขหน้าในสารบัญให้ (เป็นฟิลด์ PAGEREF อัปเดตใน Word ได้) ฝังฟอนต์ในไฟล์
- ไฟล์ PDF: สร้างจากไฟล์ Word ตัวเดียวกัน เป็นข้อความจริง (ค้นหา/คัดลอกได้) ฝังฟอนต์ เลขหน้าตรงกับ Word
- ตรวจได้ที่ `https://<โดเมน>/api/info` ต้องได้ `"render":true` (หลัง deploy รอราว 10 วินาทีให้ LibreOffice เริ่มทำงาน)
- LibreOffice ใช้หน่วยความจำราว 300–500 MB ถ้า service มีหน่วยความจำน้อยกว่านี้ให้เพิ่มใน Settings → Resources
- ถ้าเปิดบนเครื่องที่ไม่มี LibreOffice (`npm start` ธรรมดา) จะส่งออกได้เฉพาะ Word และสารบัญจะขึ้นเลขหน้าเมื่อเปิดใน Word แล้วกด "ใช่" ให้อัปเดตฟิลด์
- ตรวจคุณภาพไฟล์ที่ส่งออก: `python3 qa/check_export.py ไฟล์.pdf ไฟล์.docx` (ต้องมี `pip install pymupdf`)
- ตราสถานศึกษาบนปก อัปโหลดได้ที่แท็บ "ตั้งค่า / ส่งออก"
- ข้อมูลแผนเก็บเป็นไฟล์ `lp_<รหัส>.json` ใน Volume และรวมอยู่ในไฟล์สำรองด้วย

## ก่อนอัปเดตโค้ดทุกครั้ง

1. เปิดแท็บ **ตั้งค่า / ส่งออก** → **ดาวน์โหลดไฟล์สำรอง** (ได้ไฟล์ `timetable-backup_วันที่.json`)
2. push โค้ดใหม่ขึ้น GitHub แล้วรอ Railway deploy เสร็จ
3. ถ้าข้อมูลหาย ให้กด **กู้คืนจากไฟล์สำรอง…** แล้วเลือกไฟล์ที่ดาวน์โหลดไว้

ไฟล์สำรองนี้ใช้ได้ทั้งเวอร์ชันบน Railway และเวอร์ชันบน claude.ai ย้ายข้อมูลข้ามกันได้

## โครงสร้าง

```
server.js              เซิร์ฟเวอร์ (API + ส่งการแก้ไขแบบเรียลไทม์ด้วย Server-Sent Events)
public/index.html      หน้าเว็บทั้งหมด
public/claude-shim.js  ตัวเชื่อมหน้าเว็บกับเซิร์ฟเวอร์ (ข้อมูล ดาวน์โหลด และ AI)
seed/                  ข้อมูลตั้งต้นที่ดึงจาก "ตารางอิเล็กทรอนิกส์ 2569-2.xlsx"
```
